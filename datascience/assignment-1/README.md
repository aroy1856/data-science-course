# Employee Management System (EMS)

A simple command-line Employee Management System built with Python. It uses dictionaries for data storage and demonstrates control structures, functions, and basic input validation.

## Features

1. **Add Employee** — Add a new employee with a unique ID
2. **View All Employees** — Display all employees in a table format
3. **Search for Employee** — Look up an employee by ID
4. **Exit** — Quit the program

## Requirements

- Python 3.x (no external packages required)

## How to Run

1. Open a terminal and go to this folder:

```bash
cd datascience/assigment-1
```

2. Run the script:

```bash
python employee_management_system.py
```

Or:

```bash
python3 employee_management_system.py
```

3. Use the menu options (1–4) to manage employees.

## Sample Data

The system starts with five sample employees (IDs 101–105) so you can test View and Search immediately.
